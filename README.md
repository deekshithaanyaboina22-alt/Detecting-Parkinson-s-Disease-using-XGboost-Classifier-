# Parkinson’s Disease Detection Using XGBoost

This project focuses on detecting Parkinson’s disease from hand-drawn spiral and wave images using the XGBoost machine learning algorithm.

## Project Description

Developed a machine learning model for Parkinson’s disease detection using the XGBoost classifier on spiral and wave image datasets. Performed image-based classification to distinguish healthy and Parkinson’s-affected patterns and evaluated model performance using training and testing datasets.

## Technologies Used

- Python
- XGBoost
- NumPy
- Pandas
- OpenCV
- Matplotlib
- Jupyter Notebook

## Dataset

The dataset contains spiral and wave drawing images divided into:

- Spiral Healthy
- Spiral Parkinson
- Wave Healthy
- Wave Parkinson

Sample images are included for project demonstration.

## Project Workflow

1. Data collection from image dataset
2. Image preprocessing
3. Feature extraction
4. Model training using XGBoost
5. Model testing
6. Prediction of Parkinson’s disease from new input image

## Output

The model predicts whether the given image belongs to:

- Healthy person
- Parkinson’s affected person

Screenshots of prediction results are included in the repository.
